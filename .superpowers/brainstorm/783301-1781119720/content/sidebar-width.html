侧边栏的宽度如何控制？

侧边栏太窄看不清，太宽又占地方

A

固定宽度

设定固定宽度，例如 250px 或 300px

终端区域（自适应）
文件浏览器
250px固定

优点

  • 实现简单
  • 布局稳定

缺点

  • 不灵活
  • 大屏浪费，小屏拥挤
B

可拖拽调整（推荐）

鼠标拖拽边缘调整宽度，记住用户设置

终端区域
⋮
文件浏览器
← 拖我调整

优点

  • 灵活自定义
  • 适配不同屏幕
  • 用户体验好

缺点

  • 实现成本稍高
  • 需要保存用户设置
C

固定比例

占窗口宽度的固定百分比，例如 20% 或 25%

终端区域（75%）
文件浏览器

优点

  • 响应式，适配不同屏幕
  • 实现简单

缺点

  • 小窗口下侧边栏可能过窄
  • 不够灵活
