怎么选择要预览的文件？

用户在终端里操作，如何告诉侧边栏显示哪个文件？

A

点击文件名触发

在终端输出里点击文件路径，自动在侧边栏预览

$ ls -la
-rw-r--r-- 1 user group 2048 Jun 10 README.md ← 点击这里
-rw-r--r-- 1 user group 1024 Jun 10 config.json

优点

  • 直观，所见即所得
  • 不需要记命令

缺点

  • 需要识别终端输出中的文件路径
  • 实现复杂度较高
B

专用命令触发（推荐）

输入 preview 文件名 或 pv 文件名

$ pv README.md
✓ Preview: README.md
$ pv config.json
✓ Preview: config.json

优点

  • 实现简单可靠
  • 明确的用户意图
  • 支持Tab自动补全

缺点

  • 需要手动输入命令
  • 多一个步骤
C

自动跟随当前目录

cd到某个目录后，自动列出该目录文件列表供选择

$ cd /home/project
$ ls
/home/project
📄 README.md
📄 config.json
📁 src/

优点

  • 自动化程度高
  • 实时同步

缺点

  • 可能不是用户想要的
  • 性能开销较大
D

组合方式

命令触发(B) + 自动目录列表(C)

优点

  • 兼顾命令行和可视化
  • 灵活度最高

缺点

  • 开发成本最高
