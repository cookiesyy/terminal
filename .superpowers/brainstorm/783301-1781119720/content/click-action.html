点击文件后做什么？

在侧边栏点击文件名，接下来干啥？

A

打开系统默认编辑器

用notepad/vim/code等打开文件编辑

优点

  • 利用现有编辑器功能
  • 实现简单

缺点

  • 需要跳出终端
  • 编辑体验分离
B

在终端输入文件路径（推荐）

点击后自动在终端命令行填入文件路径，用户可以继续输入命令

用户点击侧边栏的 config.json

↓ 自动填入终端

$ ./config.json█
← 用户可继续输入: cat, vim, code 等命令

优点

  • 不打断终端工作流
  • 灵活性高，可配合任何命令
  • 符合终端使用习惯

缺点

  • 需要用户补充命令
C

自动执行cd命令（仅文件夹）

点击文件夹自动cd进入，点击文件执行cat查看内容

$ █
← 点击文件夹 src/

$ cd src
/home/project/src $ █

优点

  • 导航快速
  • 自动化程度高

缺点

  • 强制执行命令，可能不是用户想要的
  • 文件和文件夹行为不一致
