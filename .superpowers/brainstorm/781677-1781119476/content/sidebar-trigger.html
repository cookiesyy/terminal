侧边栏如何触发打开？

艹，咱们先定个基础交互方式，别搞得太复杂

A

快捷键触发

按 Ctrl+E 或自定义快捷键快速打开/关闭侧边栏

优点

  • 键盘党友好，操作快
  • 不占用屏幕空间

缺点

  • 需要记快捷键
  • 新手可能找不到
B

工具栏按钮

标题栏或标签栏旁边加个按钮，点击打开侧边栏

优点

  • 一目了然，容易发现
  • 鼠标用户友好

缺点

  • 占用标题栏空间
  • 需要鼠标操作
C

边缘悬停触发

鼠标移到窗口右边缘自动显示侧边栏（类似VS Code）

优点

  • 零学习成本
  • 不占UI空间

缺点

  • 可能误触发
  • 触摸屏不友好
D

组合方式（推荐）

快捷键 + 按钮，两种方式都支持

优点

  • 兼顾键盘和鼠标用户
  • 灵活度最高

缺点

  • 实现成本稍高
